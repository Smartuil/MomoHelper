# 墨墨 AI 学习副驾功能归档

## 产品定位

这个产品不是“再造一个背单词 App”，而是做一个贴着墨墨背单词工作流的 AI 学习副驾。

墨墨继续负责复习调度、学习计划和背词执行；AI 助手负责学习诊断、内容增强、生词整理、易混词分析和复盘建议。

第一阶段暂不考虑：

- 记忆卡
- 浏览器插件
- PDF 导入
- 独立背词系统

优先考虑：

- Web 工作台
- 微信小程序轻量入口
- 墨墨 Open API 联动
- AI 学习诊断与内容生成

## 能力边界

基于墨墨 Open API，当前可重点利用的能力包括：

- 查询单词拼写与 voc_id 的映射（不包含官方释义、音标、词频等词典数据）
- 读取今日学习进度
- 读取今日学习单词、遗忘词、未完成词
- 查询学习记录、复习计划和顽固词
- 创建和管理云词本
- 将单词加入学习计划
- 提前复习指定单词（需要账号等级 10 以上）
- 读取并管理用户自己创建的自定义释义
- 读取并管理用户自己创建的例句
- 读取并管理用户自己创建的助记

需要注意：

- 系统不直接替代墨墨 App 的背词流程。
- 不模拟用户在墨墨里的“认识 / 模糊 / 忘记”操作。
- 学习执行仍然回到墨墨完成。
- AI 主要作为诊断、整理和增强层。

## 能力缺口与约束

墨墨开放 API 的能力边界会直接影响功能设计，以下约束在立项阶段已经确认：

- 不提供官方词典内容。释义、例句、助记三类接口只能读取当前用户自己创建的内容，无法读取墨墨官方词库，因此 AI 生成的释义属于从零创作，而不是对官方释义的改写。
- 学习数据类接口处于公测状态，不保证可用性，需要用户在 App 中开启自动同步，且当日未打开 App 初始化时无法准确计算。
- 不提供按天的历史学习统计，只有今日进度快照和单词级记录。周报、月报和趋势类功能必须由平台自行每日留存快照。
- 内容创建存在硬配额：自定义释义、例句、助记三类合计每天最多创建 600 条。批量生成功能需要设计为分天执行的任务队列，不能做成一次性同步操作。
- 提前复习接口需要账号等级 10 以上，产品侧不能无条件承诺该能力；通过“添加单词并立即复习”不受等级限制。
- 不提供形近词、词根和发音数据，易混词诊断与遗忘原因分析需要由 AI 结合本地算法推断，而不是依赖官方数据。
- 只支持向学习计划添加单词，不支持移除单词，也不支持删除云词本中的单个单词。

完整的接口核对过程与降级策略见 [开放 API 能力缺口](api-capability-gap.md)。

## 产品形态

### Web 工作台

Web 适合承载复杂操作、长文本处理、批量管理和数据分析。

主要场景：

- 学习数据分析
- 遗忘词诊断
- 易混词分析
- 云词本管理
- 文本生词提取
- 批量生成释义、例句、助记
- 周报和月报

### 微信小程序

小程序适合承载轻量、随身、每日打开的功能。

主要场景：

- 今日学习进度
- 今日遗忘词
- AI 问词
- 易混词解释
- 每日复盘
- 手动添加单词
- 粘贴文本提取生词
- 一键加入云词本或学习计划

## 功能清单

### 1. 账号与墨墨连接

- 绑定墨墨 Open API Token
- 检查 Token 是否有效
- 展示 Token 状态和过期提醒
- 手动刷新学习数据
- 管理 AI 写入权限
- 管理是否允许写入自定义释义
- 管理是否允许写入例句
- 管理是否允许写入助记
- 管理是否允许创建或更新云词本
- 管理是否允许加入学习计划

### 2. 今日学习看板

- 今日目标词数
- 今日已完成词数
- 今日剩余词数
- 今日学习时长
- 今日完成率
- 今日新词
- 今日复习词
- 今日未完成词
- 今日遗忘词
- 今日重点关注词

适合端：

- Web
- 小程序

### 3. 遗忘词分析

- 今日遗忘词列表
- 最近 7 天遗忘词
- 最近 30 天遗忘词
- 高频遗忘词
- 顽固词识别
- 遗忘原因推测
- 按遗忘原因分类
- 给每个遗忘词生成补救建议
- 将遗忘词加入“顽固词本”
- 对遗忘词执行提前复习

可能的遗忘原因：

- 拼写相似
- 词义抽象
- 熟词僻义
- 中文释义混淆
- 搭配不熟
- 词根相同但含义分叉
- 缺少真实语境

适合端：

- Web 深度分析
- 小程序轻量查看

### 4. 相似词与易混词诊断

这是核心功能之一，重点解决用户经常混淆长得像、拼写接近、含义不同的单词的问题。

- 根据遗忘词自动发现形近词
- 识别只差一个字母的词
- 识别拼写高度相似的词
- 识别同词根但意思不同的词
- 识别中文释义接近但英文用法不同的词
- 识别发音接近但拼写不同的词
- 生成易混词对比解释
- 生成最小对比例句
- 生成“别再混”记忆提示
- 将易混词组加入云词本
- 为易混词写入自定义助记或例句

示例：

- adapt / adopt / adept
- affect / effect
- principal / principle
- stationary / stationery
- complement / compliment
- moral / morale
- economic / economical

适合端：

- Web 作为完整诊断台
- 小程序作为随身速查入口

### 5. AI 问词助手

- 输入单词提问
- 查询墨墨词库信息
- 解释词义
- 区分相似词
- 解释词根词缀
- 生成例句
- 生成助记
- 解释熟词僻义
- 结合用户学习状态回答
- 回答“我为什么老是忘这个词”
- 回答“这个词和另一个词怎么区分”

适合端：

- Web
- 小程序

### 6. 个性化释义

- 为单词生成更适合用户理解的中文释义
- 生成简洁版释义
- 生成考试版释义
- 生成工作语境释义
- 生成技术语境释义
- 生成论文语境释义
- 生成易混词对比释义
- 写入墨墨自定义释义
- 管理已写入的自定义释义

适合端：

- Web 批量生成和管理
- 小程序单词级轻量生成

### 7. 个性化例句

- 根据用户场景生成例句
- 根据用户输入文本生成例句
- 为遗忘词生成短例句
- 为易混词生成对比例句
- 生成考试语境例句
- 生成工作语境例句
- 生成技术语境例句
- 写入墨墨例句
- 管理已写入的例句

适合端：

- Web 批量生成和管理
- 小程序单词级轻量生成

### 8. 个性化助记

- 生成词根词缀助记
- 生成联想助记
- 生成谐音助记
- 生成对比助记
- 生成搭配助记
- 生成词源助记
- 为顽固词生成专属助记
- 为易混词生成区别助记
- 写入墨墨助记
- 管理已写入的助记

适合端：

- Web 批量生成和管理
- 小程序单词级轻量生成

### 9. 云词本管理

- 创建云词本
- 更新云词本
- 根据输入词表创建词本
- 根据遗忘词创建“顽固词本”
- 根据易混词创建“易混词本”
- 根据主题创建词本

## 第一版 MVP 建议

第一版建议聚焦在 6 个功能：

1. 绑定墨墨 Token
2. 今日学习看板
3. 今日遗忘词分析
4. 易混词与相似词诊断
5. AI 问词助手
6. 云词本创建与批量加词

这 6 个功能可以形成一个清晰闭环：

```text
墨墨学习数据
  -> AI 诊断遗忘词和易混词
  -> 生成解释、例句、助记
  -> 加入云词本或学习计划
  -> 回到墨墨复习
```
