# Impeccable Design Context

## Design Context

### Users

**三类用户**：

- 备考型学习者：考研 / 托福 / 雅思 / GRE，词量大、时间紧，需要快速定位该重点复习的词
- 职场提升型：工作场景英语，需要语境化的释义与例句
- 泛学习型：长期使用墨墨，稳定打卡，关注进度与趋势

**使用情境**：

- 桌面端做批量整理与深度分析，单次十几分钟
- 移动端（小程序）做高频短时查看，单次一两分钟

**Job to be done**：

1. 今天该重点复习哪些词？
2. 我为什么总是忘这个词？
3. 这个词和那个词怎么区分？

### Brand Personality

**严谨 · 清晰 · 克制**

像一本由专业编辑排版的**学习年报**——认真对待用户的每一条学习数据，不喧哗、不激励、不游戏化。

情感目标：让用户感到「我的学习被严肃对待了」，获得掌控感而非焦虑感。

### Aesthetic Direction

**编辑排版风（Editorial）**。

- 视觉基调：现代出版物、学术报告、书籍排版
- 参考方向：Stripe Press 的出版物、NYT 的数据版面、Klim Type Foundry 的站点、专业年鉴
- 核心手法：字体层级驱动、宽松留白、细线分隔、克制配色

**反向参考（明确不做）**：

- ❌ 通用 SaaS 仪表盘：蓝紫渐变、卡片堆叠、大圆角、通用图标
- ❌ 传统教育网站：信息拥挤、表格感强、字号小、配色老旧

**主题**：明暗双模式，跟随系统 + 手动切换，两套独立调校。

### Design Principles

1. **字先于色**——层级由字号、字重、行距建立；颜色只承担语义（状态、分类），不做装饰。
2. **留白是结构**——用间距创造分组与节奏，不靠边框和卡片去框住一切。
3. **数据要有观点**——每个数字都应回答一个具体问题，不做无意义的指标堆砌。
4. **两个模式同等对待**——深色不是浅色的反转，两套配色独立调校、各自达标。
5. **可读性优先于密度**——宁可多占一屏，也不把信息压进 12px 字号里。
